# Chương arc42

Mười hai chương và trang mục lục.

## Sub-features

- Chương 3, 5, 7 nhúng sơ đồ C4.
- Chương 6 trỏ sequence và state đã có, không chép lại máy trạng thái.
- Chương 9 ghi vì sao không dùng docToolchain.

## How to get to it (user POV)

Mở `docs/architecture/README.md` rồi vào từng chương.

## Driving it with python

`python3 diagrams/check_c4_docs.py` thất bại nếu thiếu một file chương.
