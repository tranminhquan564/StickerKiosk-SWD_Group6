# 12. Thuật ngữ

| Từ | Nghĩa |
|---|---|
| C4 | Bốn mức: context, container, component, code |
| arc42 | Mười hai chương tài liệu kiến trúc |
| ORDER.status | Trạng thái nghiệp vụ duy nhất của đơn |
| Container | Ứng dụng hoặc kho dữ liệu chạy được, không phải thùng Docker bắt buộc |
| LOC | Local controller, interface an toàn máy |
| CLD | Cloud backend |
| PAY | Nhà cung cấp thanh toán, ngoài hệ thống |
| Paid | Chỉ ghi khi webhook hợp lệ, hoặc đối soát PaymentUnknown xác nhận có tiền |
| ManualRecovery | Nhân viên xử lý. Không có lối sang Refunded trong mục 10.2 |
| REFUND_REQUEST | Hồ sơ hoàn tiền, tách khỏi status kết Refunded |
